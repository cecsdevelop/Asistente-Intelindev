# Contexto del proyecto

Este repositorio usa **[AGENTS.md](AGENTS.md)** como fuente única de verdad para el rol, el contexto técnico, las convenciones y el plan de ahorro de tokens que debe seguir cualquier asistente de IA (Claude u otro modelo) que trabaje aquí.

Antes de hacer cualquier cambio, lee `AGENTS.md` completo.

Este archivo existe solo porque Claude Code lo carga automáticamente al iniciar sesión en el repo. No dupliques contenido aquí — cualquier actualización de contexto va en `AGENTS.md`.
